SecuriTea firmware

Flashes the latest release onto a Heltec WiFi LoRa 32 V3 from this page. Works in Chrome and Edge on a computer (the browser needs Web Serial, which phones and Firefox do not have).

  1. Connect the board with a USB data cable.
  2. Press Connect and choose the board's serial port.
  3. If the port does not appear, hold the PRG button, tap RST, release PRG, and try again.
This browser has no Web Serial. Use Chrome or Edge on a computer.

The image written is the whole flash: bootloader, partition table and app. After flashing, press RST once if the board does not restart by itself. Source, pin table and the .ir file format: github.com/HamzahJE/SecuriTea.
